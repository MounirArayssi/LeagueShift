
# LeagueShift

NBA Expansion Draft Intelligence & Optimization

## Overview

LeagueShift is an interactive decision-support
platform for exploring how NBA expansion draft
rules and roster protection strategies affect
existing franchises and new expansion teams.

The initial project focuses on potential
Seattle and Las Vegas expansion scenarios.

Expansion approval, eligibility, and draft
rules must be verified. Hypothetical scenarios
are not represented as official NBA decisions.

## Core Modules

1. Contract & Eligibility Engine
2. Player Protection Optimizer
3. Expansion Draft Simulator
4. League Rules Laboratory

## Tech Stack

- Python / FastAPI
- React / TypeScript
- PostgreSQL (planned)
- OR-Tools (planned)
- pytest

## Status

Initial repository setup.

## Research Principles

- Separate confirmed data from assumptions.
- Cite sources for contract information.
- Keep draft rules configurable.
- Explain optimization decisions.
- Report uncertainty and sensitivity.
